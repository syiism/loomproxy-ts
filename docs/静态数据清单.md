# 静态数据清单

> 口径：本页只记**静态文件**，不记数据库与运行状态。正本在仓库 `tools/data/static/`，线上副本在
> `DATA_DIR/<source>/`（线上服务为 `/www/go_project/loomproxy-ts/data/`）。`_runtime/`（会话池）
> 与 `_archive/`（退役归档）不算静态字典，`/data` 与管理页都不列出。

## 1. 数据链路

```
tools/data/static/<source>/<file>.json   ← 仓库正本（本页第 2 节）
        │ tools/gen-static-dicts.mjs（pnpm run gen:dicts / check:dicts）
        ▼
plugins/<code>/src/*.generated.ts        ← 插件内生成物（自包含，不 import 仓库外路径）
        │ 随插件部署
        ▼
data/<source>/<file>.json                ← 线上副本，/data 对外提供，管理页可编辑
```

- `pnpm run check` 已包含 `check:dicts`，生成物与正本不一致即红。
- 生成物缺失时 `check:dicts` 会按正本补生成，保证新 clone 能独立跑通。
- 管理端点：`GET /admin/static-files`、`GET/PUT/DELETE /admin/static-files/:source/:name`、
  `POST /admin/static-files/move`、`POST /admin/static-files/rename-source`；管理员限定，路径白名单。

## 5. 管理页标签规则

| 标签 | 判定 |
|---|---|
| legado 书源 | 文件名 `bookSource.json` |
| 版本日志 | 文件名 `version.json` |
| 分类静态数据 | 文件名含 `cats` / `ranks` / `tags` / `categor` |
| 备份 | 文件名含 `.bak-`（优先级最高，覆盖上面几条） |
| 已退役 | 源目录属于第 4 节退役集合（`xmly/huanmeng/wd/uxx/zj`） |

未匹配的文件在页面显示「其他」，仍可编辑/删除；非 `.json` 文件标为不对外提供。

## 6. 变更规矩

- 改字典：先改 `tools/data/static/` 正本 → `pnpm run gen:dicts` → 同步线上 `data/<source>/` → 检查 `/data` 与管理页读数。
- 改 fq / qm 插件代码必须 bump 插件版本（AGENTS 硬约束）。
- 不要用 `/admin/static-files` 直接改正本再反向回写：管理页改的是**线上副本**，仓库正本要单独提交。
