# 源插件编写范式

> 一源一插件的标准结构与全部硬约束。14 个已上线源包（fq/sq/qm + asyn-panel 批 10 个 + qq_luomu）
> 已在 SDK 2 下统一；写新源前通读一遍，改源时对照检查。
> 权威代码样例：`plugins/qm_novel`（最全：会话池/加密/发现）/ `plugins/qq_luomu`（最简：纯 JSON API）。

## 1. 目录结构（SDK 2：源码即插件 + 宿主注入 SDK）

```
plugins/<code>/                       # 部署单元：整棵拷走即可在别的机器加载
├── manifest.json                     # 唯一声明位：version/code/actions/params/media_type 全在这里
├── index.mjs                         # 薄入口：export { default } from './src/index.ts'
├── src/
│   ├── sdk.ts                        # 宿主注入的 SDK 桥（工厂调用时 setSdk，其它模块 sdkOf 取）
│   ├── index.ts                      # export default (sdk) => ({ handlers, pool?, onBoot? })
│   ├── protocol.ts                   # 签名/加密/会话/端点 URL 与参数装配
│   ├── normalize.ts                  # 上游结构 → contract DTO 的纯函数
│   ├── explore.ts                    # 可选：发现页
│   ├── endpoints.ts                  # 可选：端点常量
│   └── pool.ts                       # 可选：会话/设备池
├── protocol/                         # 可选：非 TS 资产（fq_novel 的 ESM 协议树，39 个文件）
└── test/                             # 开发期夹具（不部署）：normalize/protocol 单测
```

**服务只有单版本**：`plugins/<code>/` 就是当前版本，`version` 写在 manifest 里。历史版本、升级与回退
由开发者/发布系统在外部维护（换目录 → 调 `/admin/sources/:code/reload`）。插件目录里**不许**有
`<version>/`、`deps/`、`node_modules/` 或任何软链。

**SDK 注入**（借鉴 Pi extensions 与 MusicFree）：插件源码只做 `import type`；运行时 helper
（`inBandError`/`keywordOf`/`paramString`/`scrubQuery`/`textContent`/`defineSource`/`load`，其中 `load` 是宿主的 cheerio）由宿主构造后作为参数传给
默认导出的工厂。Node 的 strip-types 会把类型导入擦掉，所以独立目录里不需要解析 `@loomproxy/*`；
contract 的 zod schema 只在测试期用（测试引用仓库根 `packages/*`，不随插件部署）。

## 2. manifest.json 字段表

```jsonc
{
  "sdk_version": "^2",              // 宿主只接受 2.x（1.x 插件会被拒）
  "version": "0.1.0",               // 当前插件版本；服务单版本，外部多版本管理
  "isolation": "in-process",        // 或 "worker"
  "entry": "./index.mjs",           // 薄入口，指回 src/index.ts
  "params": { "search": ["query", "key", "page"] },
  "meta": {
    "code": "<与目录名逐字一致>",
    "display": "显示名",
    "category": "分类短码",
    "actions": ["search", "detail", "chapter", "content"],
    "required_params": { "search": ["query"] },
    "fixed_base_url": true,
    "media_type": "novel",
    "search_tabs": [{ "tab_type": 3, "bd_id": "2", "name": "小说", "media_type": "novel" }]
  }
}
```

命名约定：`<站点>_<媒介>`（如 `sq_audio`/`sq_comic`）。平台不做源特例——形态由 manifest 与字段映射决定。

## 3. 硬约束（违反 = 违反 AGENTS.md）

| # | 约束 | 理由 |
|---|---|---|
| 1 | 上游请求只走 `ctx.fetch` | 绕开它就绕开熔断/代理/缓存/合并 |
| 2 | Node strip-only 语法；类型导入一律 `import type` | Node 24 直接跑 .ts，运行时不许解析 SDK 裸包名 |
| 3 | 运行时 helper 全部来自 `sdk`（通过 `src/sdk.ts` 桥取），不许 import SDK 值 | SDK 单例由宿主持有，插件包不携带 contract/source-kit/zod |
| 4 | 映射逻辑进 `normalize.ts` 且为纯函数 | 换源时唯一要改的地方，必须可单测 |
| 5 | 错误一律带内（`sdk.inBandError`），文案过 `sdk.scrubQuery` | 正文环节 5xx 会放大抖动；URL/签名串不外泄 |
| 6 | DTO 字段名逐字照 `packages/contract/src/legado.ts`；缺失是 `''`/0 或 `undefined` | 契约漂移 = 破坏下游 |
| 7 | 算法/常量逐字节对齐参考实现，黄金值钉住 | 签名差一位 = 整批 403 |
| 8 | 不写凭据进文档；错误文案不含 target/签名/密文 | 控制泄露面 |
| 9 | 不许 vm 跑外部 jsLib、不许同步 HTTP | Legado 桥是 Rhino 绑定，服务器没有 |
| 10 | `test/` 不连网、不连 MySQL/Redis | CI 门禁要求 |

## 4. 三种转写形态

| 形态 | 做法 | 样例 |
|---|---|---|
| **复用** | 独立 ESM 协议树随插件放在 `protocol/`，相对路径 import（`FQ_PROTOCOL_DIR` 可覆盖） | `fq_novel` |
| **转写** | 算法逐字节写进 `protocol.ts`，黄金值钉住；宿主桥换成 Node crypto + `ctx.fetch` | `sq_novel`/`qm_novel`/`tadu` |
| **直译** | 纯 JSON API：`ctx.fetch.text` + JSON.parse，映射照抄 | `qq_luomu`/`huaben` |

能转写不复用；签名体系相同的多源复用第一份实现（`hg_drama` 复用 fq 的 sign 模块）。

## 5. protocol.ts / normalize.ts 写法

- 常量区块化，注明出处；签名函数纯函数化，时钟/随机源可注入。
- 会话状态内存单例 + 注入口；跨重启凭证走平台号池（`def.pool` 声明），不自己写文件锁。
- OpenSSL 3 没有 DES：用纯 JS DES（`yueyou_novel`）或 `des-ede3-ecb` 三同钥（`tadu_novel`）。
- 正文可能是数组/密文/分页：数组 join、密文先解、分页跟完再拼。
- 章节 `itemId` 自包含（正文只有 bookId+itemId），别用带 `,{}"=` 的 base64 载体。
- normalize 的映射函数不取数；如需 `textContent`/`inBandError`，从 `./sdk.ts` 的 `sdkOf()` 取。

## 6. index.ts 骨架

```ts
import type { HandlerContext, PluginSdk } from '@loomproxy/source-kit'
import { sdkOf, setSdk } from './sdk.ts'
const inBandError = (...a: Parameters<PluginSdk['inBandError']>) => sdkOf().inBandError(...a)
// 其它 helper 同形；defineSource 同理

export default ((sdk: PluginSdk) => {
  setSdk(sdk)
  return sdk.defineSource({
    handlers: {
      async search(ctx: HandlerContext) {
        const key = sdk.keywordOf(ctx.params).trim()
        if (!key) return sdk.inBandError('缺少搜索词', { reason: 'parse_empty' })
        // 取数 + 映射，异常走 inBandFromError
      },
    },
  })
})
```

## 7. 测试要求

1. `normalize.test.ts`（必有）：上游响应夹具 → DTO 关键字段；空数据不抛。
2. `protocol.test.ts`（有算法时必有）：黄金向量来自独立实现，不许拿自己的输出钉自己。
3. 真网探针：`node tools/plugin-run.mjs <code> search query=…`（宿主注入 SDK，不起服务、不连 DB）。
4. 全量门禁 `pnpm run check`；测试文件从 `../../../packages/contract/src/index.ts` 引 schema（开发期依赖，不部署）。

## 8. 上线（手动导入 zip）

```
zip -r <code>.zip <code>/        # 包内 manifest.json（含 version）+ index.mjs + src/ + 可选 protocol/
# 面板「源插件 → 添加插件」上传 zip → 服务端解包、校验、原子替换 plugins/<code>/ 并 reload
# 多版本由开发者外部维护；服务里没有 rollback/versions 端点，也没有 manifest 文本粘贴入口
```

`POST /admin/sources/install-package` 是唯一手动导入端点；包根或 `<code>/` 前缀都认，版本号从 manifest 读。

## 9. 已知坑

- **SDK 1 插件不再加载**：manifest `sdk_version` 必须 `^2`，入口必须是工厂。
- **别在插件里放 deps/node_modules/版本目录**：check-layers 会拒绝；运行时 SDK 已由宿主注入。
- **fq_novel 的 protocol/ 必须随包**：缺它启动报 `Cannot find module …/protocol/api/core/device.mjs`。
- **DES**：OpenSSL 3 默认 provider 没有 DES → 纯 JS DES 或三同钥 3DES。
- **章节标识污染 URL**：载体别用带 `,{}"=` 的字符。
- **视频流正文**：CENC/HLS 与 novel DTO 不兼容 → content 如实报 `unsupported_media`，先扩契约再接。
- **单媒介源必须写 `meta.media_type`**，否则明细媒介全空。
